Void Linux x86_64

Repositório XBPS: Umbriel

Repositório de pacotes binários atualizados do compositor Wayland Umbriel para Void Linux (glibc x86_64).

Como usar este repositório no seu Void Linux

Para instalar e receber atualizações automáticas via sudo xbps-install -Syu:

# 1. Adicionar o repositório na configuração do XBPS
echo "repository=https://wiljapa.github.io/umbriel-void" | sudo tee /etc/xbps.d/20-umbriel.conf

# 2. Sincronizar e instalar o Umbriel
sudo xbps-install -Syu umbriel

(Na primeira vez, o XBPS pedirá confirmação para confiar na chave RSA do repositório. Pressione Y para aceitar).

Atualizações Automáticas

A partir de agora, sempre que você rodar sudo xbps-install -Syu, o Umbriel será atualizado junto com o sistema operacional!
